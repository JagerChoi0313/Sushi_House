## 三、三个核心卖点（老师大概会问）

1. **预算 + 热量 + 过敏原三重约束下的组合推荐**
   不是罗列菜品，是在预算内挑出「够吃、不超热量、避开你的过敏原」的一整套。
2. **跨地区比价**
   同一道菜（同食材 + 同形态）在七个地区的价格摆在一起，按人民币折算排序，并标出「口味不同」的那些。
3. **餐后评级把「吃了什么」变成分数**
   预算达成、热量达成、口味匹配三项算分，出「顶级/优秀/…」档位。

## 五、出问题时的兜底

### 如果模拟器白屏 / 页面数据是旧的

**九成是开发者工具的编译缓存**（这次踩过：首页徽章显示错乱，源码和产物都是对的，最后查出是工具缓存里存着旧的编译结果）。做法：

1. 完全退出开发者工具（任务管理器里结束 `微信开发者工具.exe`，要结束全部进程）。
2. 删掉这两处缓存内容（删**里面**的东西，不要删目录本身）：
   ```
   C:\Users\ROG\AppData\Local\微信开发者工具\User Data\721eda894475a9e096fa66a5dc5841ae\WeappCache\WeappCompileCache
   C:\Users\ROG\AppData\Local\微信开发者工具\User Data\533feed88e32fb3e0a6efff8dd187ff1\WeappCache\WeappCompileCache
   ```
3. 重新打开工具，等它重新编译一遍。

### 如果后端没起来 / 所有页面都是空的

重新跑第一节第 1 步，确认那个窗口还开着。`http://127.0.0.1:13000/api/world/meta` 打不开就是后端没了。

### 如果有网络版（H5）可以应急

后端已经开了跨域（`Access-Control-Allow-Origin: *`），所以浏览器里也能跑：

```powershell
cd D:\ai\工作区\dsh\小组作业\Sushi_House\_h5run
npm run dev:h5
```

然后浏览器开它提示的地址。**这条是备用路线**，界面会略有差异（比如没有小程序的原生导航栏）。
